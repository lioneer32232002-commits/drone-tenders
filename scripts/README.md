# scripts/build.mjs — 資料管線

**怎麼跑。** `node scripts/build.mjs`（Node 22+，零依賴，只用內建 `fetch`）**預設是增量更新**：重跑 14 個關鍵字的搜尋頁（約 74 個請求），只有「新出現的標案」「搜尋顯示有比既有紀錄更新的公告日期」「最後公告在 18 個月內且 status 不是 `awarded`/`failed`」才去打 `tender` 端點，其餘沿用既有 `data/tenders.json` 並重新套一次分類規則（所以改規則表不必整批重抓）。`--full` 完整重抓全部標案；`--limit 2 --keywords 無人機` 開發時只抓兩頁快速驗證；`--max-age-days N` 控制本機快取 `data/cache/`（已 gitignore，CI 不依賴）幾天內視為新鮮，`--no-cache` 完全略過快取。**上游有速率限制**（2026-09 實測：Cloudflare 約 30 req/min、突發上限 10 筆，超過回 429），腳本內建自適應節流（起始間隔 2000 ms、並發 4、遇 429 就拉長間隔並冷卻 15 秒），所以 `--full` 的 2,532 個請求**實測 125 分鐘**（SPEC 原本寫的 15 分鐘做不到），增量約 290 個請求、15 分鐘內。CI 每週一跑增量（timeout 90 分），每季第一天跑 `--full`（timeout 330 分）。任何關鍵字的搜尋頁抓不到、或標案抓取失敗率超過 2%，腳本會 `exit 1` 且不寫檔。

**怎麼改規則。** 所有分類規則都集中在檔案頂端的常數，改那裡就好，不必動下面的流程：`KEYWORDS`（搜尋關鍵字）、`CATEGORY_RULES`（`category`，陣列由上往下第一個命中者勝出，順序即優先序，每條可用 `agency` / `title` / `custom` 三種比對）、`AGENCY_GROUP_RULES`（`agency_group`，支援機關代碼 `code`、機關名稱 `name`，以及「機關代碼第二段 70–99 視為地方政府」的 `localCode`）、`DOMAIN_SEA` / `DOMAIN_GROUND` / `DOMAIN_AIR_OVERRIDE`（`domain`，`無人載具` 會撈到船艇車輛）、`AWARD_TYPES` / `FAIL_TYPES` / `TENDER_TYPES` / `PRE_TYPES`（`status` 判定用的公告類型）、`FOREIGN_CURRENCY`（外幣金額存 `null` 並計數）、`PROCUREMENT_AGENTS`（代辦採購機關）、`ORIGIN_BUCKETS`（原產地分桶）、`DRONE_IN_TITLE`（標題是否真的提到無人機）、`FMS_VENDOR` / `FMS_TEXT`（對美軍購判定）。`works` 直接看 `procurement_type === '工程'`。改完用 `--limit 2` 跑一次比對結果即可；因為增量模式會對沿用的舊資料重跑 `reclassify()`，分類規則改了下一次增量就會全面生效，不必 `--full`。

**已知限制。** 只搜標案名稱，標題沒寫「無人機」等字的案子會漏掉（例如只寫型號或「遙控載具」）；反過來，`定翼機` 這個關鍵字會撈到**有人駕駛**的飛機（內政部空中勤務總隊 BEECH 機隊維修、金門空中醫療後送），這類標題沒有無人機字樣的案子已標記 `drone_in_title: false`，`summary.json` 不計入但 `tenders.json` 仍保留；少數機關會重複使用標案案號，同一個 `unit_id + job_number` 底下混到完全無關的公告（影印機租賃、超純水系統），已依標案名稱分組只留命中關鍵字的那一組；共同供應契約多半沒有總決標金額，`award_amount` 維持 `null` 不做估算；`原產地國別` 由機關自填，未填就不計入 `by_origin`，比例記在 `data_notes.awarded_without_origin_pct`；更正公告一律以最新一筆為準，不保留歷史版本；`定期彙送` 雖然名稱不像決標公告，但帶完整決標資料，已當作 `awarded` 處理；臺灣銀行等代辦採購案的 `agency` 已改用「履約執行機關」（真正的買家），原公告機關另存 `announcing_agency`；`summary.json` 以 `domain=air` 計算（首頁預設），全領域數字在 `totals.all_domains`；`status` 的 `open`/`closed` 靠截止投標日推算，限制性招標沒有該欄位時以公告日加 90 天粗估；`summary.json` 分三軌（`domestic` / `fms` / `works`），`totals` 等所有彙總只算 `domestic`，對美軍購（4 案 503 億，得標廠商是 A. I. T. 美國在台協會）與工程類（民雄航太園區 46 億）各自獨立，`recent[]` 三軌都包含但每筆帶旗標；`fms` 靠廠商名與標題／附加說明的「軍售」「FMS」判定，若國防部改用其他寫法可能漏判。
